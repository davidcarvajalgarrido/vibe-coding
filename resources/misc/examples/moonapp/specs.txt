¿QUÉ?
Una webapp a la que el usuario indica una fecha y le dice si hay luna llena o no, y en caso de que no, le dice la fecha más próxima.

¿CÓMO?
Stack tecnológico: FullJS

Requisitos:
  Frontend:
    Formulario web
      Campo de fecha y botón de envío
      Validaciones
      Feedback
      Responsive
    HTML+CSS+JS Vanilla
    Estética similar al arte de la película Frankenstein de Guillermo del Toro
  Backend:
    API REST hecha con Node y Express
      endpoints:
        /fullmoon
          request:
            body:
              date
          response:
            boolean
        ...
    Validaciones
    Comunicación con API pública para obtener el resultado
  Todo en local
