# Lección 4 — Ejercicios

## Ejercicio 1: Delimitar contexto útil para una refactorización

1. Escribe un prompt para refactorizar una función JavaScript de 25 líneas sin cambiar su comportamiento.
2. Incluye objetivo, restricciones y formato de salida esperado.
3. Añade solo el contexto mínimo que consideres necesario.

## Ejercicio 2: Reescribir un prompt ambiguo

1. Toma el prompt: 'mejora este código y hazlo profesional'.
2. Reescríbelo para que sirva en una tarea real de backend.
3. Haz que el resultado sea verificable.

## Ejercicio 3: Diseñar una iteración correctiva

1. Imagina que la IA devolvió una solución que cambia el comportamiento de una función.
2. Redacta un mensaje de seguimiento para corregir el rumbo.
3. Indica qué debe conservar y qué debe revisar.

## Ejercicio 4: Crear un resumen de estado de conversación

1. Supón una conversación larga sobre un bug en una API.
2. Escribe un resumen operativo de 4 puntos para continuar en un nuevo hilo.
3. Incluye objetivo, hallazgos, restricción y siguiente paso.

## Ejercicio 5: Detectar anti-patrones

1. Escribe dos ejemplos breves de prompts defectuosos en tareas de desarrollo.
2. Indica qué anti-patrón comete cada uno.
3. Propón una mejora para cada caso.
