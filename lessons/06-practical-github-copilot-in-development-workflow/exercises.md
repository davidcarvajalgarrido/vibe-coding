# Lección 6 — Ejercicios

## Ejercicio 1: Preparar contexto para una función de validación

1. Crea una función vacía llamada `validateUsername` en JavaScript con un comentario que indique longitud mínima, longitud máxima y caracteres permitidos.
2. Usa Copilot para completar la implementación.
3. Revisa si la solución refleja exactamente las reglas indicadas.

## Ejercicio 2: Usar Copilot para completar una transformación de datos

1. Define un array de usuarios con propiedades `name`, `email` y `active`.
2. Escribe el inicio de una función `getActiveEmails(users)` y deja que Copilot la complete.
3. Comprueba si devuelve solo los emails de usuarios activos.

## Ejercicio 3: Generar un test inicial con ayuda de Copilot

1. Parte de una función existente llamada `sum(a, b)`.
2. Crea un archivo de test y comienza a escribir un caso de prueba para que Copilot sugiera el resto.
3. Ejecuta mentalmente o en tu entorno si el test cubre el caso esperado.

## Ejercicio 4: Refactorización pequeña asistida

1. Escribe dos bloques de código con lógica repetida para formatear nombres.
2. Extrae una función `formatName` apoyándote en sugerencias de Copilot.
3. Verifica que ambos puntos de uso siguen funcionando igual.

## Ejercicio 5: Revisión crítica de una sugerencia

1. Pide a Copilot una implementación para `normalizeEmail(email)` a partir de una función vacía.
2. Analiza si contempla entradas vacías, espacios y formato básico.
3. Corrige manualmente cualquier comportamiento insuficiente.
