# Lección 7 — Ejercicios

## Ejercicio 1: Definir un prompt agentic para analizar un bug

1. Redacta un prompt para Claude donde le pidas investigar un bug en una API que devuelve errores 500 intermitentes.
2. Incluye objetivo, contexto mínimo, restricciones y formato esperado de respuesta.
3. Haz que el resultado pida hipótesis ordenadas y siguiente paso recomendado.

## Ejercicio 2: Reescribir un prompt demasiado vago

1. Parte del prompt: 'Revisa este proyecto y mejóralo'.
2. Reescríbelo para convertirlo en una petición concreta de refactorización de un módulo.
3. Añade criterios de aceptación verificables.

## Ejercicio 3: Estructurar contexto por capas

1. Imagina que vas a pedir ayuda sobre una función lenta de procesamiento de datos.
2. Escribe un contexto dividido en objetivo, restricciones, estado actual y archivos relevantes.
3. Mantén cada bloque breve y accionable.

## Ejercicio 4: Diseñar una interacción en dos fases

1. Plantea una tarea donde Claude primero analice y luego implemente.
2. Escribe el prompt de la fase 1 y el de la fase 2.
3. Indica qué condición debe cumplirse antes de pasar a la segunda fase.

## Ejercicio 5: Preparar una revisión guiada de código

1. Define un prompt para que Claude revise una función con foco en seguridad y legibilidad.
2. Pide que clasifique hallazgos por severidad.
3. Solicita una propuesta de mejora sin modificar la lógica de negocio.
