# Lección 5 — Ejercicios

## Ejercicio 1: Mejorar un prompt ambiguo

1. Toma el prompt: 'Haz una API de usuarios'.
2. Reescríbelo incluyendo stack, restricciones y formato de salida.
3. Asegúrate de que el nuevo prompt permita validar si la respuesta es correcta.

## Ejercicio 2: Diseñar una plantilla de refactorización

1. Escribe una plantilla breve para pedir una refactorización segura.
2. Incluye contexto, límites y criterio de calidad.
3. Adáptala a un proyecto TypeScript sin nuevas dependencias.

## Ejercicio 3: Corregir una iteración deficiente

1. Parte del feedback: 'No está bien, hazlo otra vez'.
2. Convierte ese feedback en una instrucción técnica y accionable.
3. Añade una condición de validación al final.

## Ejercicio 4: Detectar anti-patrones

1. Lee este prompt: 'Rehaz mi aplicación para que sea escalable, segura y moderna'.
2. Identifica al menos tres problemas concretos.
3. Propón una versión más controlada.

## Ejercicio 5: Preparar un prompt de debugging

1. Imagina un error 500 en un endpoint de login.
2. Redacta un prompt para que la IA analice causa, cambio mínimo y verificación.
3. Limita la respuesta a pasos concretos y sin rediseñar el sistema.
