# Lección 8 — Ejercicios

## Ejercicio 1: Detectar riesgos en una propuesta de IA

1. Imagina que la IA te propone una función que usa una librería no conocida y captura todas las excepciones con `except Exception`.
2. Identifica al menos tres riesgos técnicos o de mantenimiento.
3. Escribe una versión breve del feedback que darías antes de aceptar el cambio.

## Ejercicio 2: Redactar un prompt orientado a validación

1. Escribe un prompt para pedir una función que procese archivos CSV.
2. Haz que el prompt obligue a la IA a incluir supuestos, casos límite y pruebas.
3. Mantén el prompt en 4 líneas como máximo.

## Ejercicio 3: Sanitizar contexto sensible

1. Toma este contexto: `Conecta a postgres://admin:secreto@prod-db:5432/clientes y corrige el bug del reporte ACME`.
2. Reescríbelo para poder compartirlo con una IA externa sin exponer información sensible.
3. Conserva el objetivo técnico del problema.

## Ejercicio 4: Aplicar una checklist de aceptación

1. Define una checklist de 5 puntos para revisar código generado por IA en tu equipo.
2. Incluye al menos un punto de seguridad y uno de mantenibilidad.
3. Redáctala en formato breve y operativo.

## Ejercicio 5: Diseñar una política mínima de uso responsable

1. Propón 4 reglas para un equipo que usa IA en tareas de desarrollo.
2. Incluye una regla sobre secretos, una sobre revisión y una sobre módulos críticos.
3. Escríbelas como normas claras y verificables.
