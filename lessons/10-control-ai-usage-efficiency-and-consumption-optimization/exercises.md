# Lección 10 — Ejercicios

## Ejercicio 1: Clasificar usos permitidos y restringidos

1. Define 3 tareas donde el uso de IA sería recomendable en tu equipo.
2. Define 3 tareas o tipos de datos donde debería restringirse.
3. Redacta una regla breve para cada caso.

## Ejercicio 2: Detectar ineficiencias de consumo

1. Piensa en una interacción reciente con IA para programar.
2. Identifica qué contexto sobró, qué faltó y qué se repitió.
3. Resume dos mejoras para reducir coste o latencia.

## Ejercicio 3: Diseñar métricas mínimas

1. Selecciona 4 métricas para seguir el uso de IA en un equipo.
2. Explica en una frase por qué cada una sería útil.
3. Indica cuál revisarías semanalmente y cuál mensualmente.

## Ejercicio 4: Elegir herramienta según tarea

1. Plantea 4 tareas distintas: autocompletado, refactor, documentación y análisis.
2. Asigna a cada una el tipo de herramienta o modelo más razonable.
3. Justifica brevemente si priorizas velocidad, coste o calidad.

## Ejercicio 5: Redactar una política operativa breve

1. Escribe una política de 5 líneas para uso de IA en desarrollo.
2. Incluye herramientas aprobadas, datos prohibidos y obligación de validación.
3. Añade una regla de revisión periódica.
