# Lección 12 — Ejercicios

## Ejercicio 1: Clasificar herramientas por categoría

1. Clasifica estas opciones en categorías: GitHub Copilot, Claude, OpenAI API, Ollama y LangChain.
2. Usa como categorías: asistencia inline, asistente conversacional, plataforma/modelo, solución local y framework de orquestación.
3. Escribe una justificación breve para cada caso.

## Ejercicio 2: Elegir entre cloud y local

1. Imagina un equipo que trabaja con código sensible y políticas estrictas de privacidad.
2. Indica si priorizarías una solución cloud, local o híbrida.
3. Justifica la decisión con dos argumentos técnicos y uno organizativo.

## Ejercicio 3: Definir criterios de selección

1. Propón cinco criterios para evaluar una herramienta de IA en un equipo de desarrollo.
2. Ordena esos criterios de mayor a menor importancia.
3. Explica en una frase por qué el primero está por encima del resto.

## Ejercicio 4: Construir una mini matriz de decisión

1. Compara dos herramientas reales del ecosistema usando cuatro criterios.
2. Asigna una valoración simple: alta, media o baja.
3. Concluye cuál elegirías para un equipo pequeño.

## Ejercicio 5: Diseñar un stack mínimo de adopción

1. Propón un stack de 3 piezas para un equipo intermedio que empieza con IA.
2. Incluye una herramienta de edición, una de análisis conversacional y una decisión sobre contexto o despliegue.
3. Describe el rol de cada pieza.
