# Lección 9 — Ejercicios

## Ejercicio 1: Definir una skill de revisión de código

1. Escribe una skill breve para revisar cambios en un archivo backend.
2. Incluye objetivo, 3 criterios de revisión y formato de salida.
3. Haz que la salida sea verificable por otra persona.

## Ejercicio 2: Separar una tarea en subagentes

1. Toma la tarea 'corregir un bug y añadir pruebas'.
2. Divídela en 3 subagentes con responsabilidades no solapadas.
3. Describe qué entrega cada uno.

## Ejercicio 3: Diseñar un flujo compuesto

1. Crea un flujo de 4 etapas para implementar una nueva feature pequeña.
2. Indica entrada y salida de cada etapa.
3. Añade un punto de validación intermedio.

## Ejercicio 4: Redactar un contrato de salida

1. Define un contrato para un agente que propone refactors.
2. Especifica qué puede cambiar y qué no puede cambiar.
3. Fija un formato de salida estructurado.

## Ejercicio 5: Detectar sobreingeniería

1. Piensa en una tarea simple de desarrollo cotidiano.
2. Explica por qué usar 4 subagentes sería excesivo.
3. Propón una versión simplificada del flujo.
