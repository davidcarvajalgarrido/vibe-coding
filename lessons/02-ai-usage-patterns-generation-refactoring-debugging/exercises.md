# Lección 2 — Ejercicios

## Ejercicio 1: Delimitar una petición de generación

1. Escribe un prompt para pedir una función en JavaScript que formatee un precio con moneda EUR.
2. Incluye al menos 3 restricciones técnicas y un ejemplo de entrada/salida.
3. Haz que la petición sea revisable en una sola función.

## Ejercicio 2: Convertir una petición vaga en una útil

1. Reescribe la petición 'mejora este código' para un caso de refactorización.
2. Añade una condición explícita para no cambiar el comportamiento observable.
3. Pide también una explicación breve de los cambios.

## Ejercicio 3: Preparar contexto para debugging

1. Redacta una petición de debugging para un error donde una lista puede venir como null.
2. Incluye comportamiento esperado, comportamiento real y fragmento mínimo reproducible.
3. Pide causa raíz y solución segura.

## Ejercicio 4: Añadir verificación con tests

1. Formula una petición para que la IA genere tests de una función que valida emails.
2. Pide casos válidos, inválidos y entradas vacías.
3. Indica el framework de pruebas.

## Ejercicio 5: Elegir el patrón adecuado

1. Lee este caso: 'el endpoint funciona, pero tiene lógica duplicada en tres bloques'.
2. Indica qué patrón usarías primero.
3. Justifica la elección en una frase.
